# Demo order — Job Brief → Candidate Shortlist

- **Order id:** demo-20260826-job-brief-shortlist
- **Type:** demo (presentation, placeholder data only — not connected to a real client)
- **Provider:** activepieces
- **Prospect:** Recruitment agency (demo)
- **Purpose:** Show a recruiter pasting a client job brief into a single box (or
  uploading a file), and instantly receiving an AI-ranked top-5 candidate shortlist
  from a 30-person candidate database, with a clean client-facing summary — and have
  that shortlist saved to Google Drive.

## Requested steps (as delivered)
1. Web Form: ONE "paste the client brief" text box + an optional file upload. The AI
   extracts role, location, salary band, and requirements — no six separate fields.
2. AI → Ask AI: rank top 5 candidates from the 30-person database against the brief.
3. Save the shortlist to Google Drive (file).
4. Human Input → Respond on UI: show the full Markdown shortlist + Drive link.
- Gmail draft step intentionally omitted (no connection; not requested for this demo).
