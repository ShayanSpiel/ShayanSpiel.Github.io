# Approved company assets

This directory contains reusable, approved source material shared across
Departments: company facts, founder facts, proof, case studies, and brand
references. It is not a dumping ground for drafts or runtime output.

Department-specific templates stay beside their Department. Generated drafts,
previews, videos, reports, and evidence stay under `.spielos/artifacts/` or the
public website output directory when they are published assets.
