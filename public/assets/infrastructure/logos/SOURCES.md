# Public logo sources

These files are public brand marks used to identify the architecture's example
integrations. No company credentials or private state are included.

- Codex, Claude Code, Grok, n8n, Activepieces, OpenAI, Zapier: public logo SVGs from
  the owner-supplied architecture reference's explicit `work/assets/brand` folder.
- ElevenLabs, Zendesk, LangGraph: Simple Icons v16 SVGs, via jsDelivr.
- Python and Salesforce: Devicon original SVGs, via jsDelivr.
- Apollo: https://www.apollo.io/favicon.ico
- Remotion: https://www.remotion.dev/img/remotion-white.png

Marks remain the property of their respective owners.

- `opencode.svg`: existing public website brand asset, released from `src/assets/brand-logos/opencode.svg`.
