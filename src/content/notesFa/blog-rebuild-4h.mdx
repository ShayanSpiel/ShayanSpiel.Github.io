<section class='section'>
  <SectionHead tag='مکانیزم' title='پایپلاین ۴ فایلی' sub='خزانه ← صف ← اسکریپت ← URL زنده. کل ماجرا همینه.' />

  ```
content/queue/<draft>.md       (vault side, status: ready-to-publish)
scripts/parse-frontmatter.py  (YAML → bash, helper)
scripts/publish-blog.sh       (the pipeline: transform + copy + commit + push)
~/ShayanSpiel.github.io/      (GH Pages side, _posts/, auto-builds on push)
```

        bash scripts/publish-blog.sh &lt;draft-path&gt; --yes. از اینجا به بعد با اسکریپته.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>03</div>

        <strong>اسکریپت frontmatter رو تبدیل می‌کنه</strong>
        فیلدهای Jekyll رو اضافه می‌کنه (layout, date, author). فیلدهای خزانه رو حذف می‌کنه (status, standalone_test, pillar). وایت‌لیست، نه بلاک‌لیست. قرارداد پایدار.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>04</div>
      <div class='step-body'>
        <strong>اسکریپت اسکرین‌شات‌ها رو کپی می‌کنه</strong>
        بدنه رو برای ارجاع تصویر اسکن می‌کنه. مسیرها رو حل می‌کنه. به assets/uploads/&lt;date&gt;-&lt;slug&gt;/ کپی می‌کنه. مسیرها رو توی پست بازنویسی می‌کنه.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>05</div>
      <div class='step-body'>
        <strong>اسکریپت کامیت و پوش می‌کنه</strong>

      </div>
    </div>
