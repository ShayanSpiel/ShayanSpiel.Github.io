<section class='section'>
  <SectionHead tag='مکانیزم' title='لوپ در عمل چه شکلیه' sub='دو لوپ، یک معماری. هر دو روی همون الگوی اقدام→مشاهده→ارزیابی→به‌روزرسانی→تکرار اجرا می‌شن.' />

  <div class='step-list'>
    <div class='step-item'>
      <div class='step-num'>01</div>
      <div class='step-body'>
        <strong>اقدام کن</strong>
        یک فایل منبع خام رو INGEST کن، موجودیت‌هاش رو ANALYZE کن، با صفحه‌های موجود RECONCILE کن. نیمه اول لوپ.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>02</div>
      <div class='step-body'>
        <strong>مشاهده کن</strong>
        دروازه‌های اعتبارسنجی رو چک کن. صفحه frontmatter داره؟ لینک‌ها کار می‌کنن؟ اولین سیگنال بازخورد.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>03</div>
      <div class='step-body'>
        <strong>ارزیابی کن</strong>
        به خروجی نمره بده. قبول یا رد. نقطه تصمیمی که مشخص می‌کنه لوپ جلو می‌ره یا نه.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>04</div>
      <div class='step-body'>
        <strong>به‌روزرسانی کن</strong>
        صفحه جدید رو بنویس، عمل رو لاگ کن، فایل استیت رو آپدیت کن. حالا سیستم استیت جدید رو منعکس می‌کنه.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>05</div>
      <div class='step-body'>
        <strong>تکرار کن</strong>
        فایل منبع بعدی، یا برگرد به IDLE. لوپ ادامه پیدا می‌کنه.
      </div>
    </div>
  </div>

  ```
/extract → INGEST → ANALYZE → RECONCILE → INDEX → VALIDATE → IDLE
/post    → SESSION → STRATEGY → DRAFT → GATES → QUEUE → REVIEW? → PUBLISH → ARCHIVE → ANALYZE → IDLE
```

</section>
