<section class='section'>
  <SectionHead tag='The mechanism' title='The 4-File Pipeline' sub='Vault → queue → script → live URL. That is the whole thing.' />

  ```
content/queue/<draft>.md       (vault side, status: ready-to-publish)
scripts/parse-frontmatter.py  (YAML → bash, helper)
scripts/publish-blog.sh       (the pipeline: transform + copy + commit + push)
~/ShayanSpiel.github.io/      (GH Pages side, _posts/, auto-builds on push)
```

  <div class='step-list'>
    <div class='step-item'>
      <div class='step-num'>01</div>
      <div class='step-body'>
        <strong>User writes a draft</strong>
        In content/queue/&lt;date&gt;-&lt;slug&gt;.md. The draft has status: ready-to-publish in the frontmatter.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>02</div>
      <div class='step-body'>
        <strong>User runs one command</strong>
        bash scripts/publish-blog.sh &lt;draft-path&gt; --yes. The script takes over from here.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>03</div>
      <div class='step-body'>
        <strong>Script transforms frontmatter</strong>
        Adds Jekyll fields (layout, date, author). Drops vault fields (status, standalone_test, pillar). Whitelist, not blacklist. Stable contract.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>04</div>
      <div class='step-body'>
        <strong>Script copies screenshots</strong>
        Scans body for image references. Resolves paths. Copies to assets/uploads/&lt;date&gt;-&lt;slug&gt;/. Rewrites paths in the post.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>05</div>
      <div class='step-body'>
        <strong>Script commits and pushes</strong>
        Stages the new post and uploads. Commits with a meaningful message. Pushes to origin main. GitHub Pages rebuilds. The post is live in ~30 seconds.
      </div>
    </div>
  </div>

  <Takeaway text='The whole flow is one command. The user runs the command, walks away, and the post is live. The script is the publish layer.' />
</section>
