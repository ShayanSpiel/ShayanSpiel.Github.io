<section class='section'>
  <SectionHead tag='The mechanism' title='What the Loop Looks Like in Practice' sub='Two loops, one architecture. Both run on the same Act→Observe→Evaluate→Update→Repeat pattern.' />

  <div class='step-list'>
    <div class='step-item'>
      <div class='step-num'>01</div>
      <div class='step-body'>
        <strong>Act</strong>
        INGEST a raw source file, ANALYZE its entities, RECONCILE against existing pages. The first half of the loop.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>02</div>
      <div class='step-body'>
        <strong>Observe</strong>
        Check the validation gates. Does the page have frontmatter. Do the links work. The first feedback signal.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>03</div>
      <div class='step-body'>
        <strong>Evaluate</strong>
        Score the output. Pass or fail. The decision point that decides whether the loop advances.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>04</div>
      <div class='step-body'>
        <strong>Update</strong>
        Write the new page, log the action, bump the state file. The system now reflects the new state.
      </div>
    </div>
    <div class='step-item'>
      <div class='step-num'>05</div>
      <div class='step-body'>
        <strong>Repeat</strong>
        Next source file, or back to IDLE. The loop continues.
      </div>
    </div>
  </div>

  ```
/extract → INGEST → ANALYZE → RECONCILE → INDEX → VALIDATE → IDLE
/post    → SESSION → STRATEGY → DRAFT → GATES → QUEUE → REVIEW? → PUBLISH → ARCHIVE → ANALYZE → IDLE
```

  <ProseCenter text='Two loops. One architecture. The Act→Observe→Evaluate→Update→Repeat pattern is the same.' />
</section>

  <div class='grid grid-2'>

    <Card tag='Loop pattern' title='Execute a decision right now' desc='Before creating a page: check if concept is in 2+ sources → if yes, create → if no, check if central to one source → if yes, create → if no, skip. Models are good at this.' icon='check-square' />
  </div>

  <Takeaway text='The first is a prohibition the model must hold across time. The second is a decision tree the model executes right now. Models are bad at the first and good at the second.' />
