## Core Concepts

SpielOS: Open-source AI orchestration platform. File-based agent harness with roles, skills, context management, workflows, evaluations, and long-horizon execution. Built for companies that need AI employees, not just chatbots.

Agent Harness: The structural layer of an agentic system — roles, tools, state, memory, orchestration, and human approval points — distinct from the LLM-based reasoning layer.

Agent Evals: A rigorous evaluation system for agentic behavior, including acceptance criteria, traces, scoring, regression gates, and human approval points.

Director Mode: Continuous, interactive sessions for complex work. The agent runs persistently, uses tools, reads files, and pauses for human input when needed.

Direct Mode: Run workflows directly or on a schedule. Structured execution with approval gates and history.
