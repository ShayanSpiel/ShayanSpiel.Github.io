## Core Concepts

Agent Solution Architecture: The discipline of defining, validating, and refactoring agentic systems — including workflow maps, role authority, tool boundaries, context and memory design, and eval infrastructure.

Agent Harness: The structural layer of an agentic system — roles, tools, state, memory, orchestration, and human approval points — distinct from the LLM-based reasoning layer.

Agent Evals: A rigorous evaluation system for agentic behavior, including acceptance criteria, traces, scoring, regression gates, and human approval points.

Context Engineering: The discipline of designing what goes into an LLM context window, including system prompts, memory, retrieval, and caching strategies.

Agent Loop: A state-machine pattern (Act-Observe-Evaluate-Update) used by agentic AI systems in place of static prompts.
